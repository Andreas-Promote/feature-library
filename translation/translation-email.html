New in Promote

Translation of program content

Turn any program into a fully translated copy — powered by DeepL — so you can deliver the same training in your learners' own language.

Large organisations often create programs in one language and then need localised versions for different regions or audiences. Until now that meant a slow, manual process. With translation built into the program copy flow, you can create a fully translated version in minutes.
 

How it works

1

Open any program and select Copy program

Translation is part of the standard copy flow — no separate tool needed.
2

Choose your target language

Pick any language your learners need — if it's enabled in Promote, it's ready to translate into.
3

Add translation context (optional)

Provide industry terms, tone, or role names to keep untranslated. This improves accuracy for domain-specific content.

e.g. "B2B SaaS training. Keep Coach and Facilitator untranslated."
4

Review and publish the translated program

A new independent program is created. Review it in the program builder before making it available to learners.
