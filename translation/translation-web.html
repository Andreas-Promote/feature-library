How it works

1

Open any program and select Copy program

The translation option is part of the standard copy flow — no separate tool needed.

2

Choose your target language

Pick any language your learners need — if it's enabled in Promote, it's ready to translate into.

3

Add translation context (optional but recommended)

Tell DeepL about your industry, audience, tone, or any terms that should stay untranslated. This improves accuracy — especially for technical or domain-specific content.

e.g. "B2B SaaS training. Keep role names like Coach and Facilitator untranslated."
4

Promote creates the translated program

A new, independent program is created in the target language. You can review, edit, and publish it separately from the original.

22

Languages supported

22 languages and counting — from Swedish to Japanese, your learners can train in the language they think in.

What gets translated

Translated automatically

  • Modules, content pages, and tasks
  • Goals
  • Surveys and quizzes
  • Announcement drafts

Not translated

  • Resources
  • E-learnings
  • Embedded content

Key details

Powered by DeepL

One of the highest-rated machine translation engines — known for natural, contextually accurate output.

Independent copy

The translated program is fully independent. Edit, schedule, and manage it separately without affecting the original.

Review before publishing

A built-in review prompt reminds you to check the translation in the program builder before going live.

Add-on feature

Translation must be enabled for your site. Contact your Promote administrator or Promote support to get started.
