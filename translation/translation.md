# Translation of Program Content

**Status:** Available (add-on, must be enabled per site)
**Category:** Program Design · Learner Experience
**Pillar:** Learner Experience · Program Design
**Audience:** Training Providers · L&D / Enterprise (global organisations)

---

## Summary

Translation of Program Content lets admins create a fully translated copy of any program using DeepL's machine translation engine. The result is a new, independent program in the target language that can be reviewed, edited, and delivered separately from the original — without any manual copy-pasting.

---

## The problem it solves

Large organisations and training providers frequently create programs in one language and later need localised versions for different regions, audiences, or cohorts. Without a translation tool, this has been a slow, manual, and expensive process — often requiring CS team involvement.

This feature puts translation directly in the hands of admins, making it fast and self-serve.

It works best for **cohort programs** where a facilitator runs the same program for different groups in different languages.

---

## How it works

1. Open a program and select **Copy program**
2. Choose a **target language** from the languages enabled on your site — pick any language your learners need, if it's in Promote it's ready to use
3. Optionally add **translation context** to guide DeepL — industry terms, tone, role names to keep untranslated, etc.
4. Click **Copy program** — Promote creates a new translated program automatically
5. Review the translation in the program builder before publishing

---

## Key capabilities

- **DeepL-powered** — one of the highest-quality machine translation engines, known for natural and contextually accurate output
- **Translation context field** — admins can provide guidance to improve accuracy: industry terms, target audience, preferred tone, or terms that should stay untranslated
- **Independent program copy** — the translated program is fully separate; edit, schedule, and manage it without affecting the original
- **Built-in review prompt** — a notice in the program builder reminds admins to review the translation before going live
- **Add-on feature** — must be enabled per site by a Promote administrator or Promote support

---

## Positioning notes

- Lead with the **time saved** — what used to require CS involvement or hours of manual work now takes minutes.
- For **Training Providers**: frame around the ability to offer programs in multiple languages as a product offering to their own customers.
- For **L&D / Enterprise**: frame around reaching global workforces without duplicating authoring effort.
- The **translation context field** is a genuine differentiator — most competitors offer basic machine translation with no way to guide the output. Highlight this for customers with specialised terminology.
- Always note that **this is an add-on** — it needs to be enabled. Direct customers to their admin or Promote support.
- **Not included:** automatic re-translation when source content changes (must re-copy manually), translation of resources/e-learnings/embedded content.
- **Phase 2 (not yet announced):** members choosing their preferred language within the same program — do not communicate this yet.
