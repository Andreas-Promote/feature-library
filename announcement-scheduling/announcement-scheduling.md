# Scheduled Announcements

**Status:** Available
**Category:** Communication · Facilitator Tools
**Pillar:** Learner Experience
**Audience:** Training Providers · L&D / Enterprise (facilitators)

---

## Summary

Facilitators can now schedule announcements to be published automatically at a future date and time, instead of publishing immediately or leaving them as a manual draft. Promote takes care of publishing and sending notifications at the scheduled moment — no need to log in.

---

## Context: what's an announcement?

An announcement works like a news article inside a program. Facilitators use them to share program news, reminders, or important updates with learners, coaches, or the whole program. When published, a notification is sent to each program member's email. Only facilitators can create announcements.

Typical uses: welcoming learners at the start of a program, sharing a venue change, reminding learners about upcoming deadlines, or celebrating an achievement.

---

## What's new: scheduling

Previously, announcements could only be published immediately or saved as a draft to publish manually later. Scheduling adds a third option — **Publish later** — which lets facilitators set an exact date and time for automatic publishing.

- **Prepare in advance** — write announcements whenever it suits you, days or weeks ahead of when they're needed
- **Publish automatically** — Promote publishes at the scheduled time and sends notifications without any manual action
- **Stay in control** — edit or cancel a scheduled announcement any time before it goes out; cancelling returns it to draft status

---

## How it works

1. Create or open an announcement from the **Announcements** tab as usual
2. Instead of Publish or Save draft, select **Publish later**
3. Choose the date and time
4. Confirm — the announcement remains in a scheduled state, invisible to members, until that time
5. At the scheduled moment, Promote publishes it automatically and sends notifications

---

## Where this helps

- Queue a welcome message to go out the morning a program starts, without needing to be online at that moment
- Prepare a full set of announcements in advance for a program that runs multiple times — write once, schedule per run
- Set task or deadline reminders to publish automatically a few days ahead of the due date

---

## Good to know

- **Only facilitators can create and schedule announcements** — admins do not currently have this capability. Scheduling gives facilitators a way to prepare an entire program's communications in advance, which also covers much of what's typically asked for when admins request the ability to post announcements themselves.
- **Built for programs that run again** — when a program is copied, its announcements come along as drafts, so all the writing is already done. Scheduled announcements are included too, though as plain drafts rather than with their original schedule — give them a new publish date for the new run and they're ready to go.

---

## Positioning notes

- This article should give enough context on what an announcement is for readers unfamiliar with the base feature — don't assume prior knowledge, but keep the focus on scheduling as the new capability.
- **Make clear this is a facilitator capability.** Some customers have asked for admins to be able to post announcements — this feature doesn't add that, but by letting facilitators prepare and schedule an entire program's announcements in advance, it addresses much of the underlying need. Useful context for CS if a customer asks about admin-posted announcements.
- The strongest use case is **programs that run multiple times** — facilitators can build a full announcement set once, and when the program is copied, everything comes along as drafts ready to be rescheduled. This is the headline benefit, not just a footnote.
- For **Training Providers**: frame around consistency and professionalism — announcements go out reliably even if the facilitator is unavailable at the exact moment.
- For **L&D / Enterprise**: frame around time savings for facilitators managing several concurrent or repeating programs — schedule everything in one sitting, once, and reuse it every time the program runs again.
- **Not yet available:** a "Scheduled" filter in the announcements list is still in development — do not reference it yet.
