New in Promote

Prepare now.
Publish exactly when it matters.

Facilitators can now write announcements ahead of time and let Promote publish them automatically — at the right moment, without needing to log in.

✓ Now available Communication Facilitator Tools

What's an announcement? Announcements work like a news article inside a program — facilitators use them to share updates, reminders, or important information with learners, coaches, or the whole program. When published, a notification is sent straight to each member's email.

What's new

✍️

Prepare in advance

Write announcements whenever it suits you — during program setup, in a batch, or weeks ahead of when they need to go out.

⏱️

Publish automatically

Set a date and time and Promote takes care of the rest. No need to log in and hit publish at the right moment.

🎛️

Stay in control

Edit or cancel a scheduled announcement any time before it goes out. Cancelling simply returns it to draft.

How it works

1

Write your announcement

Create it as usual from the Announcements tab — title, content, and who should see it.

2

Choose Publish later

Instead of publishing immediately or saving as a draft, select Publish later.

3

Pick the date and time

Set exactly when it should go live and confirm.

4

It publishes itself

At the scheduled time, Promote publishes the announcement and sends notifications to program members automatically.

Where this helps

👋

Queue up a welcome message to go out the morning a program starts, without needing to be online.

🔁

Prepare a full set of announcements in advance for a program that runs multiple times — write once, schedule for every run.

⏰

Set task and deadline reminders to publish automatically a few days before they're due.

🔁

Built for programs that run again. When you copy a program, its announcements come with it as drafts — all the writing is already done. Scheduled announcements are also included, though as plain drafts rather than with their original schedule, so give them a new publish date for the new run and they're ready to go.
