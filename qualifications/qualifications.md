# Qualifications

**Status:** Available  
**Category:** Credentials · Training Management  
**Pillar:** Learner Experience · Training Management  
**Audience:** Training Providers · L&D / Enterprise

---

## Summary

Qualifications lets you define, issue, and track certifications, compliance requirements, and competencies across your organisation — automatically issued when learners complete programs, with expiry tracking and notifications built in.

---

## The problem it solves

Organisations need to know which employees hold which qualifications, whether those qualifications are still valid, and when renewals are due. Without a dedicated tool, this tracking typically happens in spreadsheets or separate systems — disconnected from the training itself. Qualifications closes that gap by connecting training completion directly to credential records.

For **Training Providers**, it enables offering programs with formal certifications attached — including multi-level or expiring credentials that learners can point to as proof.

For **L&D / Enterprise** teams, it becomes an operational tool: plan training cycles around expiry dates, ensure mandatory requirements are covered across the workforce, and produce audit-ready records at any time.

## Qualification types

| Type | Expiry | Typical use case | Example |
|------|--------|-----------------|---------|
| **Certification** | Required | Formal qualifications, often with external proof | Forklift licence, first aid certificate |
| **Compliance** | Required | Mandatory recurring internal requirements | Annual IT security training, code of conduct |
| **Competency** | Optional | Skills and capabilities | Leadership training, communication skills |

## Key capabilities

- **Automatic issuance** — Qualifications are issued the moment a learner meets a program's completion criteria. Configure whether completing any one of a set of programs is sufficient, or all are required.
- **Expiry tracking** — Set a validity period in days. Qualifications transition automatically from Issued → Expiring soon → Expired.
- **Notifications** — Learners receive email notifications when a qualification is issued (via program completion), when it is approaching expiry, and on the expiry date. Admins with the Manage qualifications permission receive a daily digest of expiring and expired qualifications.
- **CSV import** — Bulk-import historical qualification records from other systems. New users are created automatically if they don't exist in Promote yet.
- **Manual entry** — Add individual records for qualifications earned outside Promote — external courses, classroom training, paper records.
- **Version history** — Create new versions of a qualification when the validity period or requirements change. Each user's record is tied to the version they held at the time of issuance.
- **Per-user view** — Admins can see all qualifications held by any user from their profile. Learners see their own qualifications in Promote.
- **Built-in report** — Export a full qualification report covering every user qualification: name, type, version, issue date, expiry date, status, and source.

---

## Getting started

1. **Enable the permission** — Grant the *Manage qualifications* admin permission to the relevant users.
2. **Create a qualification** — Go to Credentials → Qualifications → + Create new. Set the name, type, validity period, and link to one or more programs.
3. **Import existing records** (optional) — Use CSV import to bring in historical data so everything is in one place from day one.
4. **Let Promote handle the rest** — Automatic issuance, expiry tracking, and notifications run in the background. Use the built-in report for audits and planning.

## Positioning notes

- Highlight the **automatic issuance** angle for customers who currently track qualifications manually in spreadsheets — this is the biggest time-saving capability.
- For Training Providers: frame around **offering credentialled programs** as a product differentiator.
- For L&D / Enterprise: frame around **compliance readiness** and **workforce planning** — knowing who has what, and when renewals are due.
- The **CSV import** is a strong adoption argument: customers don't have to start from zero. Historical records migrate in, so the view is complete on day one.
- **Not yet available:** API endpoint for HRIS/LMS consumption of qualification data, auto-renewal, Cornerstone/SuccessFactors push integration. Do not over-promise these.
