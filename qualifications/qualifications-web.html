Qualifications lets you define, issue, and track certifications, compliance requirements, and competencies — tied directly to your training programs.

✓ Now available Credentials Training Management

Three qualification types

🏅

Certification

e.g. Forklift licence

Formal qualifications with expiry dates and optional proof of completion. Can be recorded externally.

🛡️

Compliance

e.g. IT security training

Mandatory recurring requirements that must be renewed. Always carries an expiry date.

🧠

Competency

e.g. Leadership training

Skills and capabilities where tracking expiry is optional. Flexible for development goals.

What's included

Automatic issuance

Qualifications are issued instantly when a learner meets a program's completion criteria.

Expiry tracking & alerts

Configurable notifications for learners and admins — before expiry and on the expiry date.

CSV import

Bulk-import historical records from other systems. New users are created automatically.

Manual entry

Add individual records for certifications earned outside Promote.

Version history

Update qualifications over time while preserving a full record of which version each user holds.

Built-in report

Export a full qualification report — name, version, issue date, expiry, status, and source.

Getting started

1

Enable the permission

Grant the Manage qualifications admin permission to the users who will manage this area.

2

Create your first qualification

Go to Credentials → Qualifications, click + Create new, and set the name, type, validity period, and linked programs.

3

Import existing records (optional)

Use CSV import to bring in historical qualification data so everything is in one place from day one.

4

Let Promote handle the rest

Automatic issuance, expiry tracking, and notifications run in the background. Check the report any time for a full overview.
