# Multi-language Programs

**Status:** Available (add-on, must be enabled per site)
**Category:** Program Design · Learner Experience
**Pillar:** Learner Experience · Program Design
**Audience:** L&D / Enterprise (global or multilingual audiences) · Training Providers

---

## Summary

Learning is easier in your own language. Multi-language Programs lets admins enable translations for any program so that members can select their preferred language when participating. Build once, reach everyone — language is no longer a barrier to accessing your training.

---

## The problem it solves

Organisations with multilingual workforces typically handle this one of two ways: run the program in a single language (excluding some learners), or duplicate programs manually for each language (a maintenance nightmare). Multi-language Programs removes both problems — one program, all languages, members choose their own.

---

## What makes it different

Most translation tools stop at automated output. Promote goes further with a workflow designed for L&D:

- **Side-by-side review** — before going live, admins can review original and translated content in a comparison view, with tabs to switch between all available languages
- **Manual editing in the builder** — any translation can be refined directly in the program builder, item by item — your terminology, your tone
- **Re-translate on change** — when source content is updated, Promote flags which translations are out of date. One click re-translates only what's changed, so translations never silently fall behind
- **Translation context** — guide DeepL with industry terms, preferred tone, or role names to keep untranslated, producing output that sounds like your organisation rather than a generic machine translation

---

## How to set it up

1. Open a program and go to the **Settings** tab → **Translations** → **Manage translations**
2. Select the languages to translate into (from those enabled on your site)
3. Add translation context to improve accuracy (recommended)
4. Optionally enable a notice to members that content has been automatically translated
5. Save — Promote generates the translations automatically
6. Review using the side-by-side preview or directly in the builder before publishing

---

## The member experience

- A globe icon appears in the program navigation bar
- Members can choose their preferred language before starting, or switch at any time
- Modules, tasks, goals, surveys, and quizzes all display in the chosen language
- The original language is always available as an option
- Language choice has no impact on participation, task completion, or interaction with coaches and facilitators

## Relationship to Translation of Program Content

These are two distinct features for different use cases:

| | Multi-language Programs | Translation of Program Content |
|---|---|---|
| **Best for** | Mixed-language audiences in one program | Separate cohorts in different languages |
| **How it works** | Members choose language within the same program | Creates an independent copy in the target language |
| **Maintenance** | Retranslate on change within the same program | Manage each program copy separately |
| **Delivery model** | Self-directed or mixed audiences | Cohort-based with a facilitator |

Cross-reference both features when talking to customers who have multilingual audiences — the right choice depends on how they deliver.

---

## Positioning notes

- Lead with the **before/after**: duplicate programs vs one program in every language. The maintenance burden of managing multiple copies is a pain most customers recognise immediately.
- The **review and re-translate workflow** is the key differentiator. Most competitors offer translation as a one-shot automated step with no way to review, edit, or keep in sync. Emphasise this.
- The **translation context field** is another differentiator — the output sounds like the organisation, not a generic machine translation. Use examples: "Keeps role names like Coach, Sponsor, and Buddy untranslated."
- For **enterprise customers**: frame around reaching global workforces with a consistent program experience, without the overhead of managing separate programs per region.
- For **Training Providers**: frame around offering multilingual programs as a premium product capability — one program build, delivered to any language audience.
- Always note this is an **add-on** — languages must be enabled for the site. Direct to admin or Promote support.
- Cross-reference **Translation of Program Content** for customers running cohort-based delivery.
